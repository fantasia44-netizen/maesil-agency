- 워드프레스 글 편집 → 관련 문장에 링크 삽입(에디터 링크 아이콘). 새 탭 아님, 같은 창.
- 허브 글부터 → 1주 뒤 GSC에서 ·글들 'URL 검사'로 색인 진행 확인.
- 자동화 원하면: WP REST로 일괄 삽입 가능하나 **본문 수정이라 신중**(요청 시 별도 진행).
