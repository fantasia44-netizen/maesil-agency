# 매실인사이트 · 매실K 성장 전략 마스터플랜 v2 (3-AI 통합)

> **작성:** 2026-09-07. **Claude + GPT + Gemini 세 전략안을 통합.** 세 AI가 독립적으로 같은 결론에 도달한 부분 = 고신뢰(그대로 실행). 각자 고유 기여는 병합.
> **한 줄 전략:** *매실인사이트를 직접 광고하지 않는다. **매실K(제조·자체브랜드 30억 이력)의 실전 경험 + 고객의 실제 성과**를 확산시켜 프로그램이 자연스럽게 선택되게 한다.*

---

## 0. 세 AI 합의 = 고신뢰 결론 (이건 확정)

세 개 전략안이 **독립적으로 일치**한 지점 — 논쟁 없이 실행한다:

1. **문제 = 제품 아님, "인지도·유통(도달)".** 전환은 됨(문의 옴), 파급이 1→1로 작다.
2. **성장 엔진 = 대표 신뢰 → SaaS 사용자.** "좋은 SaaS가 대표를 유명하게 만드는 게 아니라, 대표의 실전 이력·신뢰가 초기 사용자를 데려온다." (빅셀 모델)
3. **매실K 포지션 = 제조·자체브랜드 30억 (위탁·대행 아님).** 시간 지나도 유지되는 정체성: **제조→제품→브랜드→온라인판매→광고→손익→SaaS 전 과정 경험자.**
4. **블로그 = 신뢰 자산/지식DB** (광고수익·대량조회 아님). "매실K 검색 시 전문성 증명 + 콘텐츠 허브."
5. **무료 진단/도구 = Lead Magnet.** 셀러가 설명 듣기 전에 **자기 문제를 스스로 발견**하게.
6. **고객 성공 사례 = 최고 마케팅 자산** (하나 만들어 블로그·랜딩·콜드메일·강의로 재활용).
7. **Class101 = 핵심 채널로 가정 X.** 강의료보다 **매실K 인지도·퍼널 효과(CAC)**로 판단.
8. **KPI ≠ 조회수 = 문의·전환.** Attribution(어디서 온 유입이 결제까지 가는지) 필수.
9. **하지 않을 것:** 조회수용 잡콘텐츠, 매출 앞세운 강의팔이, 치트키 교육, 기능만 추가하며 마케팅 미루기, 애드센스를 핵심KPI로, 대표가 모든 고객 1:1 설득 유지.

## 1. 매실K 포지셔닝 (헤드라인)

> **브랜드를 만들고, 키우고, 알리는 사람 — 매실K**

- 간판: `몇 년차`·`매출 얼마`가 아니라 **전 과정 실경험**(제조→브랜드→판매→광고→손익→SaaS 개발).
- 이게 매실K의 가장 강한 자산이자, 경쟁사(툴 회사)와의 해자.

## 2. 매실인사이트 제품 차별화 (GPT/Gemini 기여)

경쟁사(빅셀·씨그로·장사왕)는 "매출·광고·마진 현황판". 매실은 **한 단계 더:**
- **"매출은 늘었는데 통장에 돈이 없는 이유"** = 매출 허영(Vanity metric) 타격
- **공헌이익률·실질 ROAS·채널별 통합 정산** — 수수료·차감·광고비 다 뺀 **진짜 남는 돈** 해체
- **"현황판"이 아니라 "오늘 뭘 할지(Kill or Scale)"** — 행동 지침
- 랜딩: 기능목록 X → ①셀러 문제 ②실제 사례 ③해결법 ④화면예시 ⑤무료진단 ⑥고객사례 ⑦유료

## 3. 도달 엔진 (핵심 — 세 관점 병합)

파급이 안 나는 건 **모든 채널이 대표 노력에 의존**해서다. 도달을 **① 빌린 청중(빠름) + ② 소유 자산(복리) + ③ 정타 니치**로 다층화한다.

### 엔진 A — 타 유튜브/크리에이터 협업 ★ (유튜브 차단 우회, GPT/Gemini 핵심)
직접 채널 대신 **이미 셀러 시청자를 가진 채널의 도달력**을 빌린다.
- 대상: 쿠팡셀러·스마트스토어·온라인창업·제조/OEM·마케팅·소상공인 채널
- **제안 전환**: "매실인사이트 소개해주세요" ❌ → **"시청자가 궁금할 실전 데이터·소재 + 출연자 제공"** ⭕
  - 예: "ROAS 1,000%인데 적자인 상품", "쿠팡 매출 느는데 돈 안 남는 이유", "30억까지 키우며 알게 된 숫자"
- 퍼널: 후보발굴(YouTube API) → AI 사전분석(소재 3개 제안) → **개인화 콜드메일** → CRM(발굴→발송→열람→회신→미팅→협업→게시→유입→가입→유료)

### 엔진 B — 무료 SEO 도구 ★ (Claude 기여, always-on)
검색으로 발견되는 **무료 셀러 도구** = 대표가 자는 동안에도 24시간 유입 (gblnote·장사왕이 증명).
- 후보: 쿠팡/스토어 **수수료·마진 계산기**, **공헌이익 계산기**, **키워드 경쟁강도 체커**
- 쿼리마다 고유·유용 → 구글·네이버 다 색인(의견블로그와 정반대)
- **엔진 A(협업)와 역할 분담**: 협업=빠른 도달(대표 노력 필요), 도구=복리 도달(자동). 둘 다 필요.
- 도구 결과 화면 → **무료 진단(엔진 D)** 으로 연결

### 엔진 C — 셀러 커뮤니티 (정타·무료)
네이버 카페(아프니까사장이다 등)·셀러 오픈채팅·밴드에서 **"30억 제조 브랜드" 전문가**로 활동 → 정확한 타겟 다수 노출 → 신뢰 → 문의.

### 엔진 D — 무료 진단 (Lead Magnet, 전환의 입구)
"내 쇼핑몰 수익구조 무료 진단" / "네이버·쿠팡 광고 손익 확인" → 데이터 연결 시 광고비비중·ROAS·수수료·공헌이익·비효율상품·제외키워드 **일부 무료 공개** → **자기 문제를 스스로 발견** → 유료로.

### 엔진 E — 추천 루프 (되는 입소문 복리화)
지금 문의는 우연한 소개. **시스템으로**: 고객·문의자 추천 유인(무료기간·혜택) + 성공사례 콘텐츠화 → 1→2가 아니라 **1→3→9**.

## 4. 고객 성공 사례 시스템 (자산화)

한 사례 = **Before(문제·모름·기존관리) → 발견 → Action(수정) → After(광고비·ROAS·매출·이익·업무시간)** 템플릿.
활용: 블로그·랜딩·유튜브협업 소재·콜드메일·SNS·영업자료·강의로 **재활용**.

## 5. KPI + Attribution

조회수 아님. **AARRR + 유입경로별 추적:**
`YouTube_A → 방문380 → 가입42 → 데이터연결18 → 유료5` 식으로 쌓아 **어디에 시간·돈을 더 넣을지** 판단.
- Awareness: 매실K 검색량·외부노출·협업조회 / Acquisition: 경로별 방문·무료진단·가입·채널연결 / Activation: 첫조회·핵심기능·7일재방문 / Revenue: 전환율·CAC·MRR / Referral: 추천가입·사례·협업문의
- **핵심 KPI = 월 신규 문의·유료 전환 수** (현재 1~2 → 증가)

## 6. 90일 실행안

- **Phase 1 (1~30일) 기반**: 포지셔닝 확정, 대표 소개 페이지, 랜딩 개선, UTM/Attribution 구축, 유튜버 CRM + 후보 100~200 발굴, 콜드메일·사례 템플릿, **무료 도구 1개 착수**
- **Phase 2 (31~60일) 테스트**: 유튜버 개인화 메일 발송(미팅 5~10 목표), 소·중형 채널 협업 테스트, 블로그 축적, 무료진단 퍼널 테스트, 첫 고객사례 3~5개
- **Phase 3 (61~90일) 승자확대**: 전환 좋은 유튜버·주제 파악해 반복, 사례 확산, 유료제휴 판단, Class101 ROI 재검토, 전체 퍼널 최적화

## 8. 성장 Flywheel

실제 브랜드 운영 경험 → 매실K 콘텐츠 → **타 유튜브/강의/검색/도구에서 발견** → 대표 신뢰 → 무료 진단/체험 → 자기 문제 발견 → 유료 전환 → 실제 성과 → 고객 사례 → 새 콘텐츠·협업 소재 → 더 큰 외부 노출 → 반복.
