# maesil.net — 구글 애드센스 & 검색 색인 점검 체크리스트

> **목적:** maesil.net 블로그가 ① 애드센스 **"가치 낮은 콘텐츠(Low value content)"** 판정, ② 구글 검색 **색인 거절**을 받은 것에 대해, 다른 세션에서 실제로 점검·수정할 때 쓰는 진단 체크리스트.
> **핵심 원칙(gblnote 교훈):** 색인 여부 ≠ 애드센스 심사(Mediapartners-Google는 noindex여도 평가). "가치 낮음"은 **글 개수가 아니라 원본성·유용성·구조·신뢰(E-E-A-T)**의 문제. 문장 랜덤화·키워드 스터핑은 금물, **정직·투명(출처·저자·갱신일)**이 신뢰 신호.

---

## 0. 먼저 파악할 현황 (진단 입력값)

수정 전에 이 데이터부터 확보 — 이게 없으면 뭘 고칠지 못 정함.

- [ ] **플랫폼 확인**: 워드프레스 / 티스토리 / 네이버블로그 / 자체 — **수정 가능 범위**가 여기서 갈림 (티스토리·네이버는 robots/canonical/구조 제어 제한적, 워드프레스·자체는 자유)
- [ ] **GSC(서치콘솔) 소유권 확인**됐나 → 안 됐으면 최우선 등록
- [ ] **GSC 색인 현황** (색인 > 페이지 보고서): 색인 안 된 URL을 **사유별로 분류**해 숫자 기록 (아래 §1)
- [ ] **애드센스 정책센터 메시지 원문** — "가치 낮은 콘텐츠"인지 다른 사유 동반인지 정확히
- [ ] **ads.txt** 존재·내용 (`https://maesil.net/ads.txt`) — ⚠️ 이전 확인(8/4) "찾을 수 없음". 애드센스 필수
- [ ] **robots.txt / sitemap.xml** (`/robots.txt`, `/sitemap.xml`) 존재·내용
- [ ] **사이트 규모**: 총 글 수, 카테고리 구성, 최근 발행 빈도, 주제 일관성
- [ ] **트래픽**: GA/GSC 기준 실제 유입 있는 글 vs 0뷰 글 비율

### 빠른 확인 커맨드
```bash
curl -sI https://maesil.net | grep -iE "http/|x-robots"       # 상태·noindex 헤더
curl -s https://maesil.net/robots.txt
curl -s https://maesil.net/ads.txt
curl -s https://maesil.net/sitemap.xml | grep -c "<loc>"       # 사이트맵 URL 수
curl -s https://maesil.net/ | grep -oiE '<meta name="robots"[^>]*>'   # 홈 robots 메타
```

## 1. 구글 검색 색인 거절 진단 (GSC "페이지" 보고서 사유별)

GSC → 색인 → 페이지 → "페이지가 색인되지 않은 이유"에서 **사유별로 대표 URL을 뽑아** 조치. 사유마다 의미와 처방이 다름:

| GSC 사유 | 의미 | 처방 |
|---|---|---|
| **발견됨 - 현재 색인 안 됨** (Discovered – currently not indexed) | 구글이 URL은 알지만 **크롤조차 안 함** = 품질·크롤예산 신호가 낮음 | 내부링크로 연결, 사이트맵 정리, **글 품질↑**(구글이 크롤할 가치를 느끼게) |
| **크롤됨 - 현재 색인 안 됨** (Crawled – currently not indexed) | 크롤했으나 **색인 가치 없다고 판단** = thin/중복/저품질 | 콘텐츠 **독창성·깊이 강화** 또는 통합/삭제. 가장 중요한 신호 |
| **중복 - 사용자가 표준 미지정** / **구글이 다른 표준 선택** | 유사·중복 페이지, canonical 없음 | canonical 명시, 중복 글 통합, 파라미터/태그페이지 정리 |
| **대체 페이지(적절한 표준 태그 포함)** | canonical이 다른 정본을 가리킴 | 대개 정상 — 의도한 것인지만 확인 |
| **noindex 태그로 제외됨** | 페이지에 noindex | **의도치 않은 noindex인지 확인**(테마/플러그인 오설정 흔함) |
| **소프트 404** | 실질 내용 없는데 200 반환 | 내용 채우거나 410/삭제 |
| **robots.txt 차단됨** | robots가 크롤 차단 | 차단 규칙 점검(의도치 않게 /category, /tag 막았나) |
| **리디렉션 있음 / 페이지에 리디렉션** | 3xx | 체인 정리, 최종 URL만 노출 |
| **서버 오류(5xx) / 404 (찾을 수 없음)** | 접근 불가 | 서버·링크 수정 |

- [ ] 사유별 URL 개수 표로 정리 → **최다 사유부터** 착수
- [ ] "크롤됨/발견됨-색인안됨"이 다수면 = **품질 문제**(§2·§4로) / "중복·표준" 다수면 = **canonical·중복 문제**(§3으로)
- [ ] 대표 URL 몇 개를 **URL 검사** 도구로 개별 확인 → "라이브 테스트" → 수정 후 "색인 요청"

## 2. 애드센스 "가치 낮은 콘텐츠" 진단

구글 애드센스 정책이 실제로 보는 것 — **검토·큐레이션 없는 대량/thin/스크랩 콘텐츠에 광고 금지**가 핵심 문구.

- [ ] **콘텐츠 독창성**: 각 글이 타 사이트 복붙·요약·AI 대량생성이 아닌 **원본**인가 (제품 사진·직접 경험·자체 견해)
- [ ] **최소 콘텐츠량**: 글이 실질 정보를 담을 만큼 충분한가 (주제 따라 다르나 **초박형 글 다수는 위험**)
- [ ] **주제 일관성/목적 명확성**: 블로그가 **무엇에 관한 사이트인지** 첫 화면에서 드러나나. 무관한 잡다 글 혼재 여부
- [ ] **필수 신뢰 페이지 4종** (애드센스가 강하게 봄):
  - [ ] **소개(About)** — 사이트·운영자가 누구인지, 무엇을 다루는지
  - [ ] **문의(Contact)** — 이메일/폼
  - [ ] **개인정보처리방침(Privacy Policy)** — 애드센스·쿠키 고지 포함 (애드센스 **필수**)
  - [ ] (권장) **이용약관** / **면책·제휴 고지**
- [ ] **저자·전문성 신호(E-E-A-T)**: 글쓴이 정보, 경험 근거
- [ ] **광고·제휴 vs 콘텐츠 비율**: 콘텐츠보다 쿠팡/제휴링크·광고가 많으면 감점. 본문이 광고를 압도해야 함
- [ ] **중복/스크랩 없음**: 타 블로그·언론 복제 금지
- [ ] **UX**: 모바일 대응, 로딩 속도, 침해적 전면광고 없음, 깨진 링크 없음
- [ ] **정책 금지 콘텐츠 없음**: 저작권 침해, 성인, 무단 복제 등

## 3. 기술 점검 (검색·애드센스 공통 위생)

- [ ] **robots.txt**: 필요한 경로 Allow, sitemap 지정. `/category`·`/tag`·본문 실수 차단 없나
- [ ] **sitemap.xml**: 유효·제출됨, 죽은 URL·noindex URL 미포함, 정본 URL만
- [ ] **ads.txt**: `google.com, pub-XXXXXXXX, DIRECT, f08c47fec0942fa0` — 애드센스 pub-id 정확 (⚠️ 이전 없었음)
- [ ] **canonical 태그**: 각 글에 자기 정본 canonical, 중복/파라미터 URL은 정본 지정
- [ ] **meta robots**: 의도치 않은 `noindex` 없나 (테마/SEO플러그인 기본값 점검)
- [ ] **중복 URL 정규화**: www vs non-www, http vs https, 끝 슬래시, `?ref=`·`?page=` 파라미터 → 하나로 리디렉션/canonical
- [ ] **HTTPS** 전면 적용, 혼합콘텐츠 없음
- [ ] **title/description**: 글마다 **고유**, 제목 ≤60자·설명 50~160자, 검색어 포함
- [ ] **구조화 데이터(schema.org)**: `Article`/`BlogPosting`, `Organization`, `BreadcrumbList` (리치결과 테스트로 검증)
- [ ] **Core Web Vitals**: LCP/CLS/INP (PageSpeed Insights) — 특히 모바일
- [ ] **모바일 친화성**: 반응형, 탭 타깃, 폰트 크기
- [ ] **404/soft404·리디렉션 체인** 정리

### 확인 도구
- GSC: URL 검사, 페이지 색인 보고서, Core Web Vitals, 모바일 사용 편의성
- 리치결과 테스트 / PageSpeed Insights (schema·속도)
- `curl -sI <url>`로 상태·`x-robots-tag` 헤더 확인

## 4. 콘텐츠 품질 점검 (글 단위 체크)

thin/저품질 글이 검색 색인거절 + 애드센스 "가치 낮음" 양쪽의 주원인. **글마다** 판정:

- [ ] **길이·깊이**: 실질 정보 충분한가 (한두 문단·목록만 있는 초박형인가)
- [ ] **독창성**: 복붙·AI 대량·타 글 재구성이 아닌가
- [ ] **검색의도 충족**: 제목이 약속한 답을 본문이 주는가
- [ ] **이미지**: 자체 이미지인가, `alt` 있나 (스톡·타 사이트 이미지 남발 X)
- [ ] **내부링크**: 관련 글로 연결돼 있나 (고아 페이지 X)
- [ ] **발행·수정일** 표기, 오래된 정보 갱신
- [ ] **가독성**: 소제목(H2/H3), 오탈자, 문단 구분

### thin 글 처리 결정 트리
```
글이 트래픽 0 & 얇음?
 ├─ 주제가 사이트 핵심 → 강화(내용 추가·통합)
 ├─ 비슷한 글 여럿 → 하나로 통합(canonical/301)
 ├─ 가치 없음 & 살릴 것 없음 → noindex 또는 삭제(410)
 └─ 외부 링크·트래픽 있음 → 유지하되 강화
```
> 목표: **"긁은 얇은 글 100개"보다 "제대로 된 글 30개 + 명확한 구조"**가 애드센스·검색 양쪽에 유리.

## 5. 우선순위 실행 순서

1. **즉시(반나절)**: 필수 페이지 4종(About/Contact/Privacy/약관) + **ads.txt** 설치 + robots/sitemap 정상화
2. **GSC 색인 사유 분류** → 최다 사유부터 (§1 표)
3. **thin/중복 글 일괄 정리**: 강화·통합·noindex·삭제 결정(§4 트리)
4. **핵심 글 품질 강화**: 트래픽·기대 있는 글부터 원본성·깊이 보강
5. **canonical·중복 URL 정규화** 마감
6. **재크롤·재심사**: GSC 색인 요청 + 애드센스 재신청은 **묶음 완성 후** (무지성 재연타 금지, 반영 2~4주 대기)

## 6. 판단 프레임 (gblnote에서 검증된 교훈)

- **색인 ≠ 애드센스 심사**: Mediapartners-Google는 noindex 페이지도 평가함. noindex로 숨긴다고 심사 통과 안 됨
- **"가치 낮음"의 실제 기준**: 글 수·글자 수·"원본이다"라는 주장이 아니라 **실제 유용성 + 사이트 구조/UX + 신뢰(About/정책/저자)**
- **하지 말 것**: 대량 자동생성, 필러 글 양산, 문장 랜덤화(중복회피), 키워드 스터핑, 스크랩
- **신뢰 신호 = 투명성**: 출처·저자·발행/갱신일·데이터 근거를 **정직하게** 노출. 단, 참일 때만(안 하는 걸 한다고 쓰면 역효과)
- **정직이 곧 전략**: 없는 걸 있는 척 X, 얇은 걸 두껍게 위장 X

## 7. 다음 세션에 넘길 것 (이 문서 사용법)

다른 세션에서 maesil.net 리포를 열고:
1. §0 현황부터 채운 뒤 (GSC·ads.txt·플랫폼)
2. §1 색인 사유 분류표를 실제 숫자로 채우고
3. 최다 사유 + §2 필수페이지 갭부터 착수
4. 각 조치 후 GSC URL 검사로 개별 검증, 묶음 완성 후 재심사

> 이 체크리스트는 **maesil.net 전용** (gblnote는 애드센스 승인 대기 중이라 추가 작업 보류 상태).
