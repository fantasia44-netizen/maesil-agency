## C. 가치 주입 가이드 — "여기에 실제 데이터를"
각 글은 이미 길고 구조 좋다. **부족한 건 "진짜 증거".** 글당 아래 중 1~2개만 실제로 넣어도 판정이 달라진다.

- **실제 스크린샷 1~2장** (광고 대시보드·정산·리뷰·검색결과 — 민감 수치는 가려도 됨). ⭐효과 가장 큼(구글 "1차 경험" 신호)
- **본인 실제 숫자 before/after** (ROAS·전환율·매출·광고비 — 진짜일 때만)
- **구체적 실패·시행착오 1개** ("이렇게 했다가 X 됐다") — AI가 못 쓰는 것
- **날짜·버전 명시** (언제 기준인지 — 시의성 신호. winner가 이걸로 떴음)
- **직접 촬영/제작 이미지** (스톡 말고). alt 텍스트 채우기

### 글 유형별
- **리뷰/광고/ROAS 글** → 실제 대시보드 스샷 + 실제 수치 변화
- **브랜드 글** → 본인 브랜드 실제 사례·반응 (막연한 "브랜드 중요" X)
- **정책 변화 글** → "언제 확인" 날짜 + 실제 화면 캡처
- **입문/개념 글** → 본인이 처음 겪은 구체 사례 1개
